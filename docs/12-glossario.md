# 12 — Glossário

| Termo | Definição operacional |
|---|---|
| Price Action | Leitura do comportamento do preço |
| OHLC | Abertura, máxima, mínima e fechamento |
| Swing High/Low | Máxima/mínima local confirmada |
| HH / HL | Topo mais alto / fundo mais alto |
| LH / LL | Topo mais baixo / fundo mais baixo |
| BOS | Rompimento estrutural na direção vigente |
| CHoCH | Primeiro alerta de quebra contrária à estrutura |
| MSS | Mudança estrutural com critérios adicionais definidos |
| LTA | Linha de tendência de alta |
| LTB | Linha de tendência de baixa |
| Range | Faixa lateral entre limites |
| Pullback | Retorno/correção após deslocamento |
| Reteste | Retorno a nível rompido |
| Sweep | Ultrapassagem de extremo seguida de retorno |
| Rejeição | Falha em permanecer além de uma região |
| ATR | Medida de amplitude/volatilidade média |
| R:R | Relação entre retorno potencial e risco |
| MAE | Máxima excursão adversa |
| MFE | Máxima excursão favorável |
| Look-ahead bias | Uso indevido de informação futura no teste |
| Repainting | Sinal histórico que muda com novos candles |
